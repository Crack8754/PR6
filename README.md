# ПР6. REST-ресурси CampusHub

CampusHub — API університетських подій: лекцій, зустрічей і майстер-класів. Дозволяє керувати подіями та реєструвати учасників.

## Запуск

Потрібні Node.js 22+ та npm.

```powershell
cd C:\ПР6
npm ci
npm run build
npm start
```

Базова адреса: `http://localhost:3000`.
Для запуску TypeScript: `npm run start:dev`.

Якщо порт зайнятий, задайте інший перед запуском:

```powershell
$env:PORT = '3006'
npm start
```

У цьому випадку базова адреса — `http://localhost:3006`.

- [Приклади API](docs/api-examples.md) — HTTP-запити, статуси, заголовки, тіла відповідей та сценарій PowerShell.

| Метод | Маршрут | Результат |
| --- | --- | --- |
| POST | /events | 201 + Location + створена подія |
| GET | /events | 200 + масив подій; порожній список — [] |
| GET | /events/:id | 200 + подія |
| PATCH | /events/:id | 200 + оновлена подія |
| DELETE | /events/:id | 204 без тіла |
| POST | /events/:id/registrations | 201 + Location + реєстрація |
| GET | /categories | 200 + доступні категорії |
| GET | /events/:id/registrations | 200 + реєстрації події |
| GET | /events/:id/registrations/:registrationId | 200 + конкретна реєстрація |

Останні три GET-маршрути допоміжні: дозволяють вибрати категорію, перевірити реєстрації та перейти за Location.

## Правила

- `title` — обов’язковий рядок від 1 до 200 символів після обрізання крайніх пробілів.
- `categoryId` — обов’язковий UUID наявної категорії. Невідома категорія — 400.
- `description` — необов’язковий рядок до 2000 символів; без нього зберігається `""`. Порожній рядок у PATCH очищає опис.
- `participantId` — обов’язковий UUID. Окремого довідника учасників немає, тому перевіряється формат, а не існування учасника.
- Сервер генерує UUID v4 та часові мітки UTC ISO 8601. При створенні createdAt = updatedAt.
- PATCH змінює лише передані поля; id та createdAt зберігаються. updatedAt збільшується щонайменше на 1 мс навіть за двох швидких оновлень.
- У PATCH усі поля необов’язкові, але принаймні одне потрібно передати. Порожній об’єкт — 400 EMPTY_UPDATE.
- null, неправильні типи, зайві поля й передані клієнтом id/createdAt/updatedAt відхиляються з 400.
- Нечислові ID не використовуються: ID подій, категорій, учасників і реєстрацій — UUID. Некоректний формат UUID — 400.
- UUID нормалізуються до нижнього регістру. Запис UUID великими літерами не дозволяє обійти перевірку дублікатів.
- Для відсутньої події GET, PATCH, DELETE і створення реєстрації повертають 404.
- Пара eventId + participantId унікальна; повторна реєстрація — 409. На іншу подію той самий учасник може зареєструватися.
- Видалення події каскадно видаляє її реєстрації. Реєстрації інших подій залишаються.
- Повторний DELETE повертає 404. Успішний DELETE повертає 204 без тіла, навіть без `{}`.

Для POST реєстрації спочатку перевіряються DTO та UUID, потім наявність події, потім дубль. Контролер відповідає за HTTP та Location; сервіс — за правила; repository — за Map. Перевірка дубля й запис виконуються синхронно без await, тому в одному процесі одночасні запити не створюють дублікатів.

## Категорії в пам’яті

| ID | Назва |
| --- | --- |
| 11111111-1111-4111-8111-111111111111 | Лекції |
| 22222222-2222-4222-8222-222222222222 | Зустрічі |
| 33333333-3333-4333-8333-333333333333 | Майстер-класи |

Категорії підготовлені під час запуску. CRUD категорій та окремий API учасників не реалізуються.

## Помилки

Глобальний фільтр повертає однакові поля:
`statusCode, errorCode, message, path, timestamp, traceId`.
traceId також передається в заголовку X-Trace-Id.

| Статус | errorCode | Причина |
| --- | --- | --- |
| 400 | VALIDATION_ERROR | Неправильне тіло DTO або зайві поля |
| 400 | BAD_REQUEST | Некоректний UUID у шляху або JSON |
| 400 | CATEGORY_NOT_FOUND | Категорії немає у сховищі |
| 400 | EMPTY_UPDATE | PATCH без полів для зміни |
| 404 | EVENT_NOT_FOUND | Події немає |
| 404 | REGISTRATION_NOT_FOUND | Реєстрації немає саме в цій події |
| 404 | NOT_FOUND | Невідомий маршрут |
| 409 | REGISTRATION_EXISTS | Учасник уже зареєстрований на подію |
| 413 | PAYLOAD_TOO_LARGE | JSON-тіло перевищує стандартний ліміт 100 KB |
| 500 | INTERNAL_SERVER_ERROR | Неочікувана внутрішня помилка; деталі приховані |

## Перевірка

```powershell
npm test
```

Команда компілює TypeScript і запускає 10 тестів із реальним локальним HTTP-сервером. Перевіряються:

1. Категорії та порожній список.
2. Повний CRUD, Location, UUID, часові мітки й порожня відповідь 204.
3. Валідація POST, категорій і службових полів.
4. PATCH та незмінність даних після помилки.
5. 404 і некоректні UUID.
6. Реєстрації, 409, адреса Location, зв’язки та каскадне видалення.
7. Валідація participantId до пошуку події.
8. Вісім одночасних однакових реєстрацій: один 201 і сім 409.
9. UUID великими літерами.
10. Ізоляція копій у repository та порожнє нове сховище.
